# Portifolio-hub-com-Gemini
Projetos acadêmicos e pessoais, Gerenciador de Hábitos para Estudantes de Programação, com oobjetivo de compor um perfil profissional e pessoal robusto, as melhores práticas de versionamento, colaboração e compartilhamento decódigo, e como integrar este repositório com outras plataformas profissionais, como oLinkedIn. De maneira Profissional, sou como uma pessoa dedicada, responsável e comprometida com meus objetivos, buscando constantemente aprimorar meus conhecimentos e desenvolver novas habilidades. Tenho grande interesse pela área de tecnologia, pesquisa e desenvolvimento de sistemas, procurando sempre aprender e acompanhar novas tendências.
